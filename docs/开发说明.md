# 开发说明

## 开始开发

本项目采用 pnpm 进行依赖管理
开发: `pnpm run dev`

## 分支命名规范

分支命名必须以**版本号开头**，后接说明描述，格式：

`<版本号>-<描述>`

例如：

- `v1.2.0-fix-reader-bug`（v1.2.0 版本：修复阅读器问题）
- `v1.3.0-novel-search`（v1.3.0 版本：小说搜索功能）

规则说明：

- 版本号采用 semver 格式（`vX.Y.Z`），与目标发布 tag 对应
- 版本号与描述之间用单个短横线 `-` 连接
- 描述使用短横线 `-` 分隔单词（kebab-case），简要说明分支的工作内容
- 长期维护分支（`main`、`sit` 等）不受此规则约束

## 错误处理

本项目采用全局 200 响应，只要请求正确被业务处理函数接收，则统一返回 200 HTTP 状态码，具体业务状态由响应体中的 code 指示

- 当 code 为 0 时，请求成功
- 当 code 非 0 时，请求处理异常

新增业务异常只需要在 shared\errors.ts 中编写即可，服务端额外需要在 server\types\business_exception.ts 中导出对应异常
