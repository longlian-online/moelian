# 全局确认对话框（`showConfirm`）使用指南

由于确认对话框组件（`<ConfirmDialog>`）已通过 `useConfirm` 在 Layout 上层完成挂载和状态绑定，您可以通过导入 `showConfirm` 函数并在应用中的任何地方调用它，来快速触发一个全局模态对话框，用于执行需要用户确认的操作。

## 1. 导入函数（Nuxt中不需要导入）

请从您的 Composition Function 文件中导入 `showConfirm`：

```
import { showConfirm } from './path/to/useConfirm';
// 请替换为实际的文件路径
```

## 2. 基本用法

`showConfirm` 接受一个包含对话框配置的选项对象作为参数。当用户点击对话框中的“确认”按钮时，`onConfirm` 回调函数将被执行，对话框会自动关闭。

### 示例：删除确认

```
// 假设这是您的业务逻辑代码
function handleDeleteItem(itemId: string) {
    showConfirm({
        title: '确认删除',
        message: '您确定要永久删除此项目吗？删除后将无法恢复。',
        icon: 'mdi-delete-forever', // 推荐使用与操作匹配的图标
        confirmText: '确认删除',

        // 【核心】用户点击“确认”后执行的回调函数
        onConfirm: () => {
            console.log(`项目 ${itemId} 已执行删除操作.`);
            // [此处放置实际的删除 API 调用或状态变更逻辑]
        }
    });
}
```

## 3. 可配置选项 (Options)

您可以传入一个对象来定制对话框的外观和行为。所有选项都是可选的，未提供的部分将使用默认值。

| 选项名        | 类型         | 默认值              | 描述                                                     |
| ------------- | ------------ | ------------------- | -------------------------------------------------------- |
| `title`       | `string`     | `''`                | 对话框的标题。                                           |
| `message`     | `string`     | `''`                | 对话框的主体消息，解释需要确认的内容。                   |
| `icon`        | `string`     | `'mdi-help-circle'` | 显示在标题旁的图标名称（需依赖您项目中已引入的图标库）。 |
| `confirmText` | `string`     | `'确认'`            | 确认按钮上显示的文本。                                   |
| `onConfirm`   | `() => void` | `() => {}`          | **【必须提供】** 用户点击确认按钮时执行的回调函数。      |

## 4. 流程说明

1. **调用 `showConfirm(options)`：** 将对话框状态设置为可见（`isVisible: true`），并更新 `title`, `message`, `icon`, `confirmText`, 和 `onConfirm`。
2. **用户操作：**
   - **点击确认：** 触发 `handleGlobalConfirm` -> 执行 `dialogState.onConfirm()` -> 设置 `isVisible: false` (对话框关闭)。
   - **点击取消或关闭：** 触发 `hideConfirm` -> 设置 `isVisible: false` (对话框关闭) -> **不执行 `onConfirm`**。
